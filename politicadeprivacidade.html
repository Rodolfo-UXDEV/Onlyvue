POLÍTICA DE PRIVACIDADE — Onlyvue®

Última atualização: Janeiro de 2026

1. QUEM SOMOS

A Onlyvue Platform Ltd, empresa operacional do grupo Group Onlyvue Limited, holding internacional proprietária da marca registrada Onlyvue®, ambas em processo de abertura societária no Reino Unido, com administração sediada em Londres – Inglaterra, é a controladora dos dados pessoais tratados no site https://www.onlyvue.com (“Site”).

A Onlyvue se preocupa com a segurança, confidencialidade e integridade dos Dados Pessoais tratados no exercício de suas atividades.

Esta Política poderá ser atualizada periodicamente para refletir alterações legais ou regulatórias. Alterações relevantes serão publicadas no Site e comunicadas aos Usuários cadastrados.

2. DADOS PESSOAIS COLETADOS

Podemos coletar as seguintes categorias de Dados Pessoais:

  • Dados de contato: nome, sobrenome, telefone, e-mail, documento de identidade;
  • Dados de pagamento: informações sobre compras realizadas (processadas por Stripe e Pagar.me);
  • Outros dados pessoais: idade, gênero, fotografias e demais informações fornecidas voluntariamente;
  • Dados sensíveis: dados biométricos utilizados exclusivamente para verificação de idade e identidade;
  • Dados de uso do Site: endereço IP, dados de navegação e cookies.
3. COMO COLETAMOS SEUS DADOS

Seus dados são coletados quando você:

  • Navega no Site;
  • Cria conta ou perfil;
  • Publica ou responde anúncios;
  • Entra em contato com nosso suporte;
  • Caso forneça dados de terceiros, você declara possuir consentimento válido para tanto.
